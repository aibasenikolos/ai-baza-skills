# Growth Tactics — onboarding, aha moment, retention, pricing, метрики

То чего нет в saas-validator-deep. Универсальные паттерны под планирование.

**Важно:** этот файл — **база знаний паттернов**, не источник истины. Используй его чтобы понять что искать у конкурентов через WebFetch (см. `research-guide.md`). В план записываем не «делаем pricing decoy» абстрактно, а «делаем 3 тарифа как у [конкурент.com/pricing] — у них в середине Pro, и это работает». Паттерны из этого файла без привязки к реальному конкуренту = нейрослоп.

## 1. Onboarding до aha moment

**Aha moment** — первый момент когда юзер думает «вау, оно реально работает / решает мою проблему». Это НЕ «зарегался», не «увидел dashboard». Это конкретное событие.

**Примеры aha:**
- **Slack:** отправил первое сообщение команде → пришёл ответ
- **Notion:** создал первую страницу с таблицей и связанной БД
- **Figma:** пригласил коллегу и увидел его курсор в реальном времени
- **HeadshotPro:** загрузил селфи → увидел первый AI-портрет
- **AI-диспетчер эвакуатора:** настроил номер → принял тестовый звонок → AI правильно зафиксировал заявку

**Правила онбординга:**
- **Aha наступает за 60 секунд** или меньше (B2C) / 5-10 минут (B2B). Если дольше — отвалится 50-90%
- **Не больше 5 шагов** до aha
- **Не «заполни профиль»** в первом шаге. Сразу к ценности
- **Tooltip + progress bar** или checklist в боковой панели — юзер видит сколько до победы
- **Skip кнопка** на необязательных шагах. Принуждение убивает retention
- **Empty state с примером** — если у юзера нет данных, покажи демку с ними

**В план записываем:**
- Что считается aha
- Сколько шагов и времени до него
- Что юзер делает в каждом шаге

## 2. Retention механика — что заставит вернуться

Без retention продукт = подписка которая отваливается на 2-3 месяце.

**Базовые механики:**

| Механика | Как работает | Под какие продукты |
|----------|-------------|--------------------|
| **Transactional notification** | Каждый раз когда продукт делает работу — уведомление с результатом («принят звонок, заявка ушла Васе»). Юзер видит что платит не зря | B2B SaaS, автоматизация |
| **Daily/weekly digest email** | «На этой неделе ты заработал X, обработал Y». Юзер открывает почту = думает о продукте | Все типы |
| **Streak / gamification** | «Ты тренируешься 7 дней подряд, не ломай!» | B2C habit, fitness, learning |
| **Daily reason to come back** | Новый контент / новые лиды / новые заявки каждый день | Лид-генерация, marketplace |
| **Social hook** | Приглашение коллег / клиентов в продукт. Уйти = бросить команду | B2B collaboration, marketplaces |
| **Persistent value** | Накопленные данные / связи / контент которые потеряются | CRM, базы, заметки |

**Hook Model (Nir Eyal):**
- **Trigger** (внешний или внутренний — push, email, привычка)
- **Action** (юзер делает простое действие)
- **Variable reward** (получает ценность — иногда крутую, иногда обычную)
- **Investment** (вкладывает что-то — данные, связи, время — что повышает switching cost)

**Конкретные примеры:**
- Push «новый лид» → клик → видит контакт → добавляет в CRM (investment)
- Email digest → клик → видит отчёт → шарит в команду (investment)

**В план записываем:** 1-2 retention механики которые встроены в продукт с MVP.

## 3. Pricing структура

**Один тариф vs 3 тарифа:**

| Подход | Когда использовать |
|--------|-------------------|
| **Один тариф** | Продукт простой, ICP узкий, нет per-seat. ₽4990 и точка. Ускоряет MVP |
| **3 тарифа (Basic / Pro / Enterprise)** | Есть разные сегменты с разной WTP. Anchor через Pro |
| **Per-seat** | B2B где ценность растёт с командой |
| **Per-usage** | API, infrastructure, AI токены |

**Decoy эффект:**
- 3 тарифа: ₽1990 / ₽4990 / ₽9990
- Pro (₽4990) сделан так что выглядит явно лучшим выбором (≈ Enterprise по фичам, ≈ Basic по цене)
- Это толкает большинство на Pro. Без decoy все ушли бы на Basic

**Annual discount:**
- 10-20% off за оплату годом
- Уменьшает churn (юзер заплатил год вперёд — не отвалится через месяц)
- Улучшает cash flow

**Триал vs Hard paywall:**
- **Hard paywall** (платить сразу) — лучше для B2B, выше LTV, ниже сигнапы. Marc Lou всегда так
- **7-14 дней trial** без карты — лучше для B2C, больше сигнапов, ниже конверсия в платящего
- **Trial с картой** — гибрид, конверсия выше но сигнапов меньше
- **Freemium** — для соло-фаундера зло. Бесплатные едят ресурсы, не платят

**В план записываем:** одна цена, одна модель (триал / paywall), причина выбора.

## 4. Лендинг — структура и hero

**Универсальная структура (по очереди сверху вниз):**

1. **Hero** — заголовок (5-10 слов) + sub (10-20 слов) + CTA + visual (видео/GIF/скриншот)
2. **Social proof** — лого клиентов / отзывы / цифры (X happy users)
3. **Проблема** — что болит у юзера (3-5 буллетов)
4. **Решение** — как мы решаем (3-5 буллетов с скриншотами/иконками)
5. **Как работает** — 3 шага (sign up → setup → result)
6. **Фичи** — 4-6 блоков с иконкой / иллюстрацией / коротким описанием
7. **Кейсы / отзывы** — 2-3 истории с фото юзеров и цитатой
8. **Цены** — 1-3 тарифа с CTA
9. **FAQ** — 6-10 вопросов которые отрабатывают возражения
10. **Финальный CTA** — большая кнопка + повтор главного бенефита

**Hero hook — формула:**
- **[Главная боль ЦА]** + **[как мы решаем]** + **[результат за время]**

Примеры:
- «Принимай звонки клиентов 24/7 без диспетчера. AI ловит заявки пока ты спишь.»
- «Generate professional headshots in 5 minutes. No photographer needed.»
- «AI диспетчер для соло-эвакуаторщика. Не пропускай ни одного ночного звонка.»

**CTA-кнопки:**
- НЕ «Подробнее» / «Узнать больше». Это слабо
- ДА «Попробовать 7 дней бесплатно» / «Поймать первый звонок» / «Получить headshot за 5 минут»

**Trust элементы:**
- Лого платежей (Stripe / ЮКасса / VISA)
- Лого партнёров если есть
- «Нас используют 1000+ человек» (если правда)
- Скриншот реального dashboard
- Гарантия возврата 7-30 дней

## 5. Социальные доказательства

Без social proof первые юзеры не купят. Что включить:

- **Отзывы:** фото + имя + компания/город + цитата (2-3 предложения, конкретные результаты)
- **Лого клиентов:** logo wall (если хоть кто-то использует)
- **Цифры:** «X юзеров», «Y тысяч обработано», «Z часов сохранено»
- **Кейсы:** 1-3 истории «было / стало» с реальными цифрами
- **Скриншоты с UGC:** юзеры показывают наш продукт у себя в TG / соцсетях

**Если ноль юзеров на старте:**
- Founder story («Я делал X, столкнулся с Y, поэтому построил Z»)
- Показать что строил публично (Twitter / TG посты с прогрессом)
- Бета-юзеры с пометкой «Early access — присоединяйся»
- Чужие отзывы по проблеме (цитаты из Reddit / форумов о боли которую решаем)

## 6. Метрики которые меряем

**Воронка (от visit до payment):**
- Visits → Sign-ups (sign-up rate, цель 2-5% для cold traffic, 10-30% для warm)
- Sign-ups → Activated (activation rate = % дошедших до aha, цель 50%+)
- Activated → Paid (trial-to-paid, цель 10-20% для B2C, 20-30% для B2B)
- **MRR** (Monthly Recurring Revenue) — главная цифра
- **Churn** (% отвалившихся в месяц, цель < 5-10%)

**Юнит-экономика:**
- **CAC** (Customer Acquisition Cost) — сколько потратил на привлечение одного платящего
- **LTV** (Lifetime Value) = средний месячный платёж × средний срок жизни (1 / churn)
- **LTV / CAC** должен быть ≥ 3, иначе экономика не работает
- **Payback period** — за сколько месяцев CAC окупается. Цель < 12 мес

**Продуктовые:**
- DAU / MAU (если retention важен)
- Time to aha (среднее время от sign-up до aha)
- Feature adoption (какие фичи используют, какие нет)

**В план записываем 4-6 главных метрик с целевыми цифрами на 30/60/90 день.**

## 7. Конкретные примеры по нишам

### B2B SaaS (типичный)
- Onboarding: 3 шага через wizard, aha = первое автоматизированное действие
- Retention: weekly email digest + transactional notifications
- Pricing: 3 тарифа per-seat, decoy в середине, annual 15% off
- Trial: 14 дней без карты
- Лендинг: hero с видео-демо, лого клиентов, кейсы с цифрами

### B2C consumer (типичный)
- Onboarding: 1-2 шага, aha = первый результат за 60 сек
- Retention: push + streak + daily new content
- Pricing: 1 цена / месяц или год, hard paywall после онбординга
- Trial: hard paywall или 3 дня
- Лендинг: hero с до-после, viral hook, UGC отзывы

### B2B локальный сегмент (русский новичок)
- Onboarding: персональный звонок основателя + ручная настройка
- Retention: TG-уведомления о ценности + ежемесячный отчёт по email
- Pricing: 1 простой тариф ₽3-10K/мес, ИП на ЮКассе
- Trial: 7 дней бесплатно с настройкой совместно
- Лендинг: hero с видео реальной работы, отзывы пилотов, телефон владельца

## 8. Антипаттерны

- ❌ Длинный онбординг с 10 шагами «настрой профиль»
- ❌ Aha moment после 5 минут setup
- ❌ Freemium с бесплатным тарифом
- ❌ Pricing «От $XX/мес — связаться с продавцом» (на старте — отпугивает)
- ❌ Лендинг без visual в hero (просто текст и кнопка)
- ❌ Нет social proof, или фейковые отзывы
- ❌ Нет retention механики (юзеры платят 1 месяц и уходят)
