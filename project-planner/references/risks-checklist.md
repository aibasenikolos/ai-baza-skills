# Risks Checklist — юр / тех / платёжки / ассеты

Чеклист для секции «Юр / тех / платёжный риски» в плане. Проверь все пункты под продукт юзера. Если что-то применимо — клади в план одной строкой.

## 1. Юридические риски (РФ)

### 152-ФЗ «О персональных данных»
- **Применимо если:** собираешь любые ПД (имя, email, телефон, IP, cookies)
- **Что нужно:**
  - Согласие на ОПД при регистрации (чекбокс «Согласен с обработкой ПД»)
  - Политика конфиденциальности на сайте
  - Уведомление в Роскомнадзор (бесплатно, через сайт РКН)
  - Серверы должны быть в РФ для ПД граждан РФ (Yandex Cloud / VK Cloud / Selectel)
  - Если используешь зарубежные сервисы (Stripe, AWS) — регистрация трансграничной передачи
- **Штраф за нарушение:** до 500K руб (ст. 13.11 КоАП), за повтор до 6 млн руб

### ФЗ-38 «О рекламе»
- **Применимо если:** делаешь массовую рассылку email / SMS / TG DM
- **Что нужно:**
  - Согласие получателя на рекламу (чекбокс)
  - Маркировка рекламы в Telegram через ОРД (если платная)
  - В каждом рекламном письме — кнопка «Отписаться»
- **Штраф:** до 500K руб **за каждое сообщение** без согласия

### Лицензии Минцифры / Роскомнадзора
- **Применимо если:**
  - Оператор связи (своя SIP-телефония, продажа номеров) — лицензия Минцифры
  - Оператор персональных данных — регистрация в РКН
  - Лотерея / гемблинг — лицензия Минфина
  - Образовательная деятельность — лицензия (для онлайн-курсов с дипломом)

### Юр. лицо
- **ИП на УСН 6% «доходы»** — стандарт для соло-фаундера
- **Самозанятость** — нельзя если есть работники, лимит ₽2.4M/год
- **ООО** — нужно для крупных B2B-клиентов (часто требуют), для лицензий, для инвестиций

### Налоги
- УСН 6% от выручки (без расходов)
- НДС: при УСН нет, при ОСН (ООО без УСН) — 20%
- Чеки: онлайн-касса через ЮКассу (включена в их платёжку)

### B2C и защита прав потребителей
- Оферта на сайте обязательна (ГК РФ 437)
- Возврат в 14 дней по дистанционной торговле
- Указать юр.адрес, ИНН, ОГРН в footer

### Авторское право
- Если контент пользовательский — модерация + право удаления
- Если используешь чужие изображения — лицензии (Unsplash / Pexels OK, Google Image НЕТ)
- AI-генерированный контент: пока серая зона, но риск претензий по обучающим данным

## 2. Технические риски

### Зависимость от сторонних API
- **Что проверить:**
  - Цена за 1000 запросов (масштабируется?)
  - SLA и uptime (99.9% / 99.99%)
  - Лимиты бесплатного тарифа vs платного
  - Что делаем если API упал на час / меняет цены / закроется
- **План B:** альтернативный провайдер на крайний случай (например, OpenAI → Anthropic → Together)

### Latency / точность / hard parts
- Если в продукте есть голос / видео / real-time — это риск
- Если AI-точность критична (медицина / юр) — нужны fallback на человека
- Если география ЦА широкая — CDN / multi-region

### Безопасность
- HTTPS обязательно
- Rate limiting на API
- Защита от brute force (auth)
- Backup БД ежедневно

### Скорость разработки
- MVP за 2-4 недели, не за полгода
- Не пили кастомные сложные фичи если есть готовое
- Used parts: Auth, payments, email, analytics — всё с полки

## 3. Платёжные риски

### Если ЦА — РФ (рубли)

- **ЮКасса** — стандарт, рекуррент, СБП, карты, кошельки
  - Требует: ИП или ООО (самозанятый — нельзя для рекуррента)
  - Договор подписывается онлайн, документы 1-3 дня
  - Комиссия 2.8-3.5%
  - Чеки на email автоматом
- **Альтернативы:** Robokassa, ProdamUs, Cloudpayments
- **СБП** — 0.4-0.7% комиссии, дешевле карт

### Если ЦА — запад (доллары)
- **Stripe** — нужно зарубежное юр.лицо (US LLC, UK LTD, Estonia OÜ)
- **Paddle** — Merchant of Record, юр.лицо РФ можно, они сами разбираются с налогами / VAT. Комиссия 5%
- **LemonSqueezy** — аналог Paddle, проще для соло-фаундера
- **Gumroad** — для одиночных продаж и подписок, очень просто

### Если ЦА — глобал
- Paddle / LemonSqueezy — лучший вариант для соло (нет своего юр.лица)
- Stripe + US LLC — если готов оформлять компанию (через Stripe Atlas / Firstbase ~$500)

### Карты для оплаты иностранных сервисов (для основателя)
- Vercel / OpenAI / Anthropic / Apify — нужна **зарубежная карта**
- Российские карты не принимают
- Решения: карты через зарубежного посредника / партнёров (на свой страх и риск, изучи репутацию)

## 4. Ассеты — что подготовить ДО кода

Чеклист обязательного:

- [ ] **Название продукта** + домен (.com / .io / .ru / .app)
- [ ] **Логотип** (можно через Looka / Brandmark / Midjourney за час)
- [ ] **Favicon** (сгенерировать из логотипа)
- [ ] **Тексты лендинга** (hero, проблема, решение, фичи, FAQ)
- [ ] **Скриншоты / GIF** для visual hook
- [ ] **Юр.лицо** (ИП / ООО / самозанятый — для платёжки)
- [ ] **ЮКасса / Stripe аккаунт** (зависит от рынка)
- [ ] **Зарубежная карта** для оплаты сервисов
- [ ] **Email с домена** (founder@yourdomain.com — через Resend / Mailgun)
- [ ] **Telegram канал / WhatsApp Business** (контакт для саппорта)
- [ ] **Оферта** (генератор docs.google.com или юрист от ₽5K)
- [ ] **Политика конфиденциальности** (генератор)

## 5. Что НЕ должно быть блокером

Иногда юзер думает что что-то ему критично, но на старте можно без:

- Не нужно ООО, достаточно ИП
- Не нужен дизайнер — Tailwind + shadcn/ui = норм лендинг
- Не нужна реклама — холодные каналы первые 10 платящих
- Не нужен copywriter — Claude напишет тексты лендинга
- Не нужен бухгалтер — УСН 6% сам рассчитывается
- Не нужен юрист — оферта по шаблону, политика по шаблону
- Не нужна команда — соло до $10K MRR норма

## 6. Что записывать в план

В секцию «Юр / тех / платёжный риски» — одна строка на каждый применимый риск:

```
**Юридические:**
- 152-ФЗ: серверы РФ (Supabase нет — нужно Yandex Cloud + согласие ОПД)
- ОРД: не применимо (нет массовой рекламной рассылки)
- Лицензия Минцифры: не нужна (не оператор связи, Voximplant — посредник)

**Технические:**
- Зависимость от Voximplant (если упадёт — звонки не идут). План B — Telphin
- Voice latency 2 сек — риск, нужно тестить с реальными звонками первую неделю

**Платёжный:**
- ЮКасса: нужно ИП — у юзера есть. Зарегистрировать рекуррент 1-3 дня
- Карта для Voximplant — РФ принимает, проблем нет
```

Не более 5-7 строк всего. Если больше — режь, оставь критичное.
