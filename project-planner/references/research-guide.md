# Research Guide — как делать ресёрч под план SaaS

Это инструкция для Шага 3 workflow. Цель — найти **конкретные имена, цифры, цены, ссылки**. Не «какие есть конкуренты вообще».

## ГЛАВНОЕ ПРАВИЛО — реальные ссылки, не выдумки

Если в плане нет ссылок на реальные сайты конкурентов, реальных скринов hero, реальных цен — это **нейрослоп**. Юзер должен иметь возможность кликнуть на каждую ссылку в плане и проверить «вот у Х действительно так».

**Обязательный минимум перед записью в план:**

1. **WebFetch минимум 2 лендинга конкурентов** (не только результаты поиска). Открой реальный сайт. Выпиши hero / цены / структуру дословно. Запомни URL.

2. **Каждое утверждение в плане имеет источник.** «Делаем pricing decoy» — это нейрослоп. «Делаем 3 тарифа как у [Competitor].com/pricing — у них Pro в середине это работает» — это конкретно.

3. **Юзеру показываем варианты с ссылками.** Не «сделаем как у топов индустрии». А «посмотрел [X.com], [Y.com], [Z.com]. На мой взгляд лучше зайдёт стиль X — потому что [причина]. Кликни, посмотри. Согласен?»

4. **Никакого «обычно в SaaS делают...».** Это сигнал что Клод выдумывает из общих знаний. Если ниша незнакомая — найди реальные примеры. Если ниша известная — всё равно найди 1-2 реальных лендинга чтобы юзер видел.

## Принцип скорости

**Параллельно, не последовательно.** В одном сообщении кидай 3-5 WebSearch + WebFetch вызовов. Это в 5 раз быстрее последовательно.

**Конкретика, не общие слова.** Если нашёл «есть несколько решений» — перезапусти запрос точнее. Тебе нужны имена + цены + ссылки.

## Что нельзя писать без проверки источника

| Нельзя писать общими словами | Нужно подкрепить ссылкой |
|------------------------------|--------------------------|
| «Делаем pricing decoy» | Скрин страницы цен реального конкурента |
| «Hero с видео в первом экране» | URL конкурента где так сделано |
| «Trial 7 дней без карты» | Скрин сигнап-страницы где так |
| «Onboarding 3 шага» | URL продукта с таким онбордингом |
| «Daily TG-notification» | Пример реального продукта который так делает |
| «Лого клиентов в social proof» | Скрин конкурента с logo wall |
| «Тариф ₽4990/мес» | Цены 2-3 реальных аналогов в РФ |

Если для пункта не нашёл источник — два варианта:
1. Запусти ещё ресёрч (этот пункт важный)
2. Удали пункт (раз нет основания — не пиши)

## Поток A — Конкуренты глобально (запад)

### Запросы

Используй один из вариантов под продукт:

```
[ниша] SaaS top tools 2025 2026 pricing comparison
best [категория] software for [сегмент] 2026 reviews
[название аналога] alternatives competitors pricing
[боль которую решаем] software solution 2026
```

Примеры:
- «AI voice receptionist software pricing 2026»
- «small business call answering service top tools»
- «automated dispatcher tow truck industry software»

### Что искать

- **3-5 имён конкурентов** с ссылками на их сайты
- **Цены** (если на лендинге не указана — отметить «pricing on request» как red flag для enterprise)
- **Tier структура** — сколько тарифов, что в каждом
- **Hero-фраза на лендинге** (заголовок главной страницы)
- **Год основания** (если 2024+ — это новый рынок, есть место)

### Критика конкурентов (gold mine)

Это самое ценное. Где искать **1-2★ отзывы:**

- G2.com — `[product] reviews G2`
- Capterra — `[product] capterra reviews`
- Trustpilot — `[product] trustpilot`
- Reddit — `[product] reddit reviews experience`
- ProductHunt — `[product] producthunt comments`

Что выписывать:
- Что юзеры **критикуют** (ценные жалобы → наши фичи)
- Что **отвалились пользоваться** (boilingpoint → наша возможность)
- **Чего просят добавить** (feature requests → наши фичи V2)

## Поток B — Конкуренты в РФ/СНГ

### Запросы

```
[ниша] сервис Россия 2026 цена
лучший [продукт] для [сегмента] СНГ
[боль] решение для бизнеса РФ
аналоги [западного продукта] в России
```

Примеры:
- «AI диспетчер звонков сервис цена»
- «голосовой бот приём заявок аналог Россия»
- «автоматизация эвакуатора служба IT-решение»

### Что искать дополнительно (специфика РФ)

- Работают ли **в РФ напрямую** или нужен зарубежный аккаунт
- Принимают ли **рубли через ЮКассу/СБП**
- Есть ли **152-ФЗ соответствие** (серверы в РФ)
- **Кейсы и отзывы** на vc.ru / habr / spark
- Цены в **рублях** (если только в долларах — ниша новая для РФ)

### Где искать

- Yandex поиск (Google в РФ урезан)
- vc.ru — лучшая площадка для русских кейсов
- spark.ru — русские стартапы
- Habr — техническая ниша
- v3.ru — мнения предпринимателей

### Гэп для нас

После ресёрча выпиши явно:
- **«У запада есть X, в РФ нет/слабо — гэп для нас»**
- **«У РФ конкурентов нет фичи Y которую мы делаем»**
- **«Цена $X на западе → ₽X в РФ дешевле, но и средний чек ниже»**

## Поток C — Дизайн-референсы

### Запросы

```
[категория] best landing pages 2026 examples
[продукт] homepage design inspiration
top SaaS onboarding examples 2026
[ниша] dashboard UI examples
```

Также полезно:
- `[конкурент].com` — открыть и проанализировать
- siteinspire.com — каталог дизайнов
- landbook.com — лендинги
- mobbin.com — мобильные паттерны
- pageflows.com — onboarding flows

### Что выписывать

**Hero-секция:**
- Один заголовок (5-12 слов) + сабтайтл (10-20 слов)
- Главный CTA (текст кнопки)
- Видео / GIF / скриншот / illustration
- Social proof (лого клиентов, отзывы, цифры)

**Структура страницы (порядок секций):**
- Hero
- Проблема (что болит)
- Решение (как мы решаем)
- Фичи (3-6 блоков)
- Социальные доказательства (отзывы, кейсы, цифры)
- Цены
- FAQ
- CTA повторно

**Цвета и тон:**
- Пастель / minimal / bold / dark mode
- 2-3 акцентных цвета
- Шрифт (sans / serif / mono)

**Onboarding:**
- Сколько шагов до первого результата
- Куда юзер попадает после регистрации (dashboard / setup wizard / empty state)
- Прогресс-индикатор
- Skip / required steps

### Что копировать в наш MVP

Не копировать всё. Выбери:
- **Структуру лендинга** одного конкурента (того кто конвертит лучше)
- **Onboarding-паттерн** другого (если он короче)
- **Pricing-блок** третьего (если структура чище)

В план записать: «Лендинг как у [X], onboarding как у [Y], цены как у [Z]».

## Поток D — Маркетинговые и retention приёмы

### Что исследуем

**Hook на лендинге:**
- Какой one-liner используют (выписать дословно)
- Какая выгода в первые 2 секунды
- До-после / трансформация / цифры

**Trial / paywall:**
- Hard paywall сразу / 7-14 дней триал / freemium
- Карта при регистрации или нет
- Что блокируется в триале

**Onboarding до aha moment:**
- За сколько шагов юзер видит ценность
- Что считается aha (момент «вау, оно работает»)
- Email/push после регистрации
- Welcome flow (3-5 шагов)

**Retention механики:**
- Daily/weekly notification
- Streak / gamification
- Social hook (приглашения, комментарии)
- Email digest
- Persistent value (накопленные данные → высокий switching cost)

**Pricing структура:**
- Один тариф vs 3 тарифа vs 5
- Decoy в середине (Pro дороже Plus, но Plus ≈ Pro по фичам — толкает на Pro)
- Per-seat / per-usage / flat
- Annual discount (10-20% off)

**Социальные доказательства:**
- Отзывы (как форматируют — фото + имя + компания + цитата)
- Лого клиентов (logo wall)
- Цифры (X happy customers, Y messages sent, Z hours saved)
- Video testimonials

### Запросы

```
[конкурент] pricing strategy
SaaS onboarding best practices 2026
B2B SaaS retention tactics
how to write hero copy SaaS landing
[ниша] customer testimonials examples
```

### Где искать паттерны

- LennysNewsletter.com — лучший контент про SaaS growth
- Demandcurve.com — playbooks по маркетингу
- Reforge.com — фреймворки про retention/growth
- ProductLed.com — про onboarding и self-serve
- GoodBetterBest.io — pricing страницы каталог
- Saaspricing.io — каталог pricing-страниц

## Поток E — Дистрибуция под нишу

### Что исследуем

Где конкретно тусуется ЦА:
- TG-чаты и каналы (по ключевым словам ниши)
- Сабреддиты (для запада)
- Профильные форумы (например, mtbtalk.ru для велосипедистов)
- Группы ВК / FB
- Slack-сообщества (для B2B запада)
- LinkedIn группы

### Запросы

```
[ниша] telegram чат сообщество
[профессия] форум 2026
[ниша] subreddit community
[профессия] LinkedIn group active
лучшие телеграм чаты для [сегмент]
```

Также:
- TGStat.com — поиск каналов и чатов TG
- Combot.cc — топ TG чатов
- Reddit search «r/[нишa]»

### Парсинг источники под нишу

Для B2B локального бизнеса:
- 2GIS / Яндекс.Карты (по категории + город)
- Avito (бизнес-объявления)
- Контур.Фокус / Rusprofile (юр.лица)
- ЕГРЮЛ выгрузка
- LinkedIn (для запада)

Для специфики:
- HH.ru / Superjob — кто нанимает в нише (B2B клиенты)
- Wildberries / Ozon — продавцы определённой категории
- Cian.ru / Avito — сегмент недвижимости
- Domain databases (whois.ru) — владельцы сайтов

### Что записать в план

В секцию «Где первые 10 платящих»:
- 2-3 конкретных канала с именами (не «TG-чаты», а «10 чатов: t.me/X, t.me/Y, t.me/Z»)
- Конкретный парсинг источник если применим
- Конверсии и ожидания (из 100 контактов → 5 ответов → 1 платящий)

## Финальный синтез — формат с обязательными URL

После всех потоков напиши **синтез на 5-10 строк перед записью в план**. Каждое утверждение — с реальной ссылкой.

```
ЧТО НАШЛИ (с источниками):

Конкуренты:
- Запад: 
  - Goodcall.com — $59/мес, hero "AI receptionist that never sleeps", 7-day trial.
    Сильное: чистый онбординг 3 шага. Слабое: только английский.
  - Rosie.ai — $49/мес, hero "Answer every call. Win every customer." Trial есть.
    Сильное: pricing per-minute. Слабое: жалобы на latency (G2 1-2★ отзывы).
- РФ:
  - Voximplant Avatar — ₽3500/мес, лендинг voximplant.com/avatar.
    Сильное: 152-ФЗ. Слабое: позиционирование на enterprise, не на соло.
  - В нише соло-эвакуаторщиков прямых конкурентов не нашёл — гэп.

Дизайн-инсайт: 
- Hero как у Goodcall.com — короткий заголовок + видео реального звонка + CTA.
- Pricing как у Rosie.ai — простой tier один + per-minute доплата.
- Onboarding как у [конкретный URL] — 3 шага: connect number → set rules → test call.

Маркетинг-инсайт:
- Hard paywall + 7-day trial без карты (как у обоих).
- Hero копи: «Поймай каждый звонок. Не потеряй ни одной заявки.»

Retention-инсайт:
- TG-уведомление «принят звонок Васи, отправлен Пете, цена 3500 руб» 
  каждый раз когда продукт работает (паттерн как у Stripe transactional emails).

Дистрибуция: 
- TG-чаты: t.me/evakuatory, t.me/towservice (если найдены — реальные URL)
- Парсинг 2GIS по запросу «эвакуатор + город» в 5 миллионниках
```

Этот синтез вкладываем в план в секции «Конкуренты», «Дизайн-референсы», «Visual hook», «Onboarding», «Retention», «Где первые 10 платящих».

## Тон общения с юзером после ресёрча

Не вываливай весь синтез сразу. Подавай блоками с обоснованием и **давай юзеру выбор**:

> Посмотрел 3 лендинга в твоей нише:
> - **goodcall.com** — hero «AI receptionist that never sleeps» + видео звонка
> - **rosie.ai** — hero «Answer every call. Win every customer.» + GIF
> - **voximplant.com/avatar** — текстовый, без видео
>
> На мой взгляд под твою нишу лучше **стиль Goodcall** — короткий слоган + 30-сек видео реального звонка. Простому соло-эвакуаторщику нужно увидеть как оно работает за 5 секунд.
>
> Что выбираем — Goodcall, Rosie или свой вариант?

И так для каждой ключевой секции (дизайн, цены, onboarding, retention).

## Антипаттерны ресёрча

- ❌ Записать в план «делаем как делают топы» без конкретных имён и URL
- ❌ Записать «есть пара конкурентов» — нужны минимум 2 реальных имени
- ❌ Не открыть лендинги через WebFetch (только результаты поиска = поверхностно)
- ❌ Не искать критику в отзывах 1-2★ (там золото)
- ❌ Записать «маркетинг через соцсети» без конкретных тактик и каналов
- ❌ Запустить 5 запросов последовательно (час вместо 5 минут)
- ❌ Выдумать pricing/onboarding из головы без проверки на конкурентах
- ❌ Не дать юзеру выбор — вываливать решения без альтернатив
