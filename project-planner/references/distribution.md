# Distribution — где первые 10 платящих

Меню каналов для русскоязычного соло-фаундера без аудитории. Бюджет 0-50K руб. Цель — 10 платящих за 30-60 дней.

В план кладём **2-3 канала**, не больше. Распыляться нельзя.

## Реальность

- Первые 10 — самые сложные. Нет соц.доказательств, каждый сигнап — ручной труд
- Pieter Levels / Marc Lou / Cal AI — у них аудитория росла 5-10 лет. Новичок без аудитории — другая лига
- Без своего канала первые 10 закрываются **только** через холодные действия + личные связи

## 10 рабочих каналов (от простого к сложному)

### 1. Прямые продажи знакомым (день 0, обязательно)

Список 30-50 человек из контактов / TG / LinkedIn попадающих в ЦА. Лично каждому: «Делаю штуку для X. Покажу — скажешь честно».

**Цифры.** Из 30 сообщений 5-10 пойдут смотреть, 1-3 заплатят. **Конверсия 5-10%** — выше любого холодного канала.

**Делать всегда. Независимо от ниши.**

### 2. Постинг в тематических ТГ-чатах (бесплатно, 0-3 клиента/неделя)

Найти 10-30 чатов где сидит ЦА. **Не спамить с порога.** 2 недели давать пользу в комментариях. Потом нативно упомянуть продукт.

**Где искать чаты:** TGStat, Combot Top, поиск по ключевым словам.

**Правила:**
- Не кидать ссылки в первый день
- Отвечать в комментариях по делу
- Когда спрашивают — упоминать продукт без давления
- Спросить админа в личке про размещение, иногда дают за бартер

**Цифры.** Из 30 чатов трафик из 5-7. На каждом 1-2 заинтересованных в неделю. **5-15 разговоров → 1-3 продажи в неделю.**

### 3. Холодные DM в Telegram (риск бана + юр.риск)

Парсишь участников целевых чатов (Telethon), пишешь с личного аккаунта персонализированно.

**Жёсткие лимиты 2025:**
- **50 DM/день** — потолок для нового аккаунта. Дальше PeerFloodError + бан
- Прогретый аккаунт (год+, фото, переписки) — до 100-150/день
- Telegram с 2023 сильно ужесточил антиспам

**Как не банить:**
- Прогревать аккаунт 2-3 недели
- Минимум 30% уникальности каждого сообщения (через Claude API)
- Без ссылок в первом сообщении
- Не более 5-10 DM в час
- Проверять статус через @SpamBot

**Конверсии.** Персонализация → 5-10% reply. Generic → 1-2% и быстрый бан. **100 DM → 5-10 ответов → 1-2 платящих.**

**Юр.риск РФ:** Массовая рассылка без согласия = реклама = штраф **до 500K руб за каждое сообщение** (ФЗ-38, ФЗ-152). Для микробизнеса риск низкий, но есть.

### 4. Парсинг 2GIS / Яндекс.Карты (B2B локального бизнеса)

Если ЦА — кафе / салоны / автосервисы / стоматологии — парсишь телефоны с 2GIS / ЯК.

**Инструменты:**
- Parsing Master (готовый парсер 2GIS / Google Maps / ЯК)
- Mirdata, Leads-solver («белая зона»)
- DataForSEO API
- Самописный Playwright + Claude Code (бесплатно)
- n8n + Apify actor для Google Maps

**Сценарий через Claude Code:**
```
1. Claude пишет Playwright скрипт → парсит 2GIS по запросу 
   "стоматологии Москва" → 500 карточек
2. Claude фильтрует (есть TG / есть сайт)
3. Claude генерит персонализированные сообщения
4. Claude через Playwright или Telegram API шлёт в TG
```

**Цифры.** 500 контактов за час. ~30% с активным TG. Конверсия в звонок ~5%. **500 → 5 продаж примерно.**

### 5. Холодный email (B2B, безопаснее DM)

Парсишь email через Hunter.io / Snov.io / Apollo (запад) или Контур.Фокус / Rusprofile (РФ). Шлёшь через Instantly / n8n.

**Цифры B2B 2025:**
- Average reply rate: **3-5%**
- Топ-кампании: **15-25%** (узкий ICP + персонализация)
- Персонализация дальше имени = **+340%** (Hunter.io 11M писем)
- Cadence 3-7-7 (день 1, 3, 10) ловит **93%** ответов

**Стек:** Instantly.ai (~$37/мес) + Hunter.io + Claude API + n8n workflow.

**Ключевое.** Прогрев домена **2-4 недели** до старта. Без прогрева — спам, домен сжигается. Никогда с основного.

### 6. Reddit / IndieHackers / ProductHunt (если на запад)

Главные каналы для международных продуктов. Бесплатно.

- **Reddit.** 2 недели «давать пользу» в r/SideProject, r/SaaS, нишевые сабреддиты
- **IndieHackers.** Build-in-public, прогресс, цифры, факапы
- **ProductHunt.** Один день запуска. 100-300 сигнапов реально, 10-30% триал → 5-30 платящих

### 7. ВКонтакте группы (для определённых ниш)

ЦА — мамы, школьники, регионы, лайфстайл. Группы 50-200K, прямые DM админам, бартер.

**Не работает:** B2B SaaS, IT, диджитал-эксперты — они в TG.

### 8. Микро-инфлюенсеры за бартер (B2C)

30-50 микро-блогеров (5-50K в TG/IG/YT). Бесплатный год премиума за честный обзор.

**Цифры.** 50 предложений → 10-15 ответят → 3-5 договорятся. Каждый = 50-300 переходов. Бесплатно.

Базовая стратегия Cal AI ($30M ARR), HeadshotPro и большинства B2C SaaS на старте.

### 9. Реферальная программа (после первых 10)

«Приведи друга — оба +14 дней / 30% / лайфтайм». **Не на старте.** После первых 10 платящих.

### 10. Свой ТГ-канал и контент (долгая игра, 6+ месяцев)

Постить про прогресс, цифры, факапы. На 6-12 месяцев — базовый канал лидов.

**Когда плох.** Если нужно заработать сейчас. Это задел на 2-3-4 продукт.

## Эталонная стратегия для соло-фаундера из СНГ

**Не распыляться. Выбрать 2-3.**

### Если ты обычный предприниматель / маркетолог

1. Список 30-50 знакомых из ЦА → личные DM
2. 10-15 тематических ТГ-чатов → пользу 2 недели → нативное упоминание
3. Свой ТГ-канал с нуля → процесс параллельно

**Цель за 30 дней:** 3-5 платящих + 50-200 подписчиков на канале.

### Если ты можешь кодить через Claude

Добавить:
4. Парсер 2GIS / TG-чатов → 500 контактов в неделю
5. Холодный email на B2B-сегмент
6. n8n workflow для follow-up

**Цель за 30 дней:** 5-10 платящих через смесь холодных и тёплых каналов.

### Если продукт на запад

Заменить TG-чаты на:
- Reddit (r/SideProject + ниша)
- IndieHackers build-in-public
- ProductHunt запуск на 30-й день

**Цель:** 10-30 платящих через ProductHunt + Reddit.
